# LifeOS

Follow the shared engineering rules in [AGENTS.md](AGENTS.md).

Read the [README](README.md), [PRD](docs/product/PRD.md) and [roadmap](docs/product/ROADMAP.md) before changing product scope. Use [development instructions](docs/DEVELOPMENT.md) for setup and commands, and [system architecture](docs/architecture/SYSTEM.md) for module boundaries.

Keep each task small: understand the current code, implement the authorized scope, run relevant checks, review the diff and report remaining issues. Do not add future roadmap features as part of foundation work.
